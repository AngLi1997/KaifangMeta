# 知识库与 Agent 版本

> 平台 · AI 模块。相关：[能力目录](catalog.md)（可见性、ACL 过滤、应用空间）、[知识库与 Agent 引擎（WeKnora）](weknora.md)。

- 知识库版本 = 不可变快照：文档集 + 切片配置 + 向量模型版本 → 索引产物。实时库（如馆藏全文）例外：文档集随业务推送增量变化，只有切片配置、向量模型变更才重建新版本，见 [WeKnora](weknora.md)。
- Agent 版本 = 不可变快照：提示词、模型、工具（锁定算子版本）、绑定的知识库版本。
- 统一流程：草稿 → 发布 → `prod` 别名；回滚即切换别名；发布前跑评测集回归（评测集由标注工单产出）。
- 索引与 Agent 运行由 WeKnora 承担，版本、别名、评测记录在 AI 模块 `ai` schema。
