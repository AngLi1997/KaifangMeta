# 知识库与 Agent 版本

> 平台 · AI 模块。完整管理与运行时设计见 [AI 模块：Agent 管理与运行](../ai/overview.md)。相关：[能力目录](catalog.md)（可见性、ACL 过滤、应用空间）、[WeKnora 知识库引擎](weknora.md)。

- 知识库版本 = 不可变快照：文档集 + 切片配置 + 向量模型版本 → 索引产物。实时库（如馆藏全文）例外：文档集随业务推送增量变化，只有切片配置、向量模型变更才重建新版本，见 [WeKnora](weknora.md)。
- Agent 版本 = 不可变快照：运行时适配器、模型配置修订、提示词版本、Skills、MCP 工具 Schema、绑定的知识库版本与安全策略。
- 统一流程：草稿 → 校验 / 评测 → 发布 → `prod` 别名；回滚即切换别名。发布后依赖不可变，调整提示词、工具、权限或运行时都要生成新版本。
- AI 模块 `ai` schema 保存资源版本、依赖快照、会话、运行事件和审计；首版 Agent 运行由 DeepSeek Harness 适配器承担，Pi Agent 与 WeKnora Agent 作为后续适配器。
- 新会话解析并锁定当前 `prod` 版本；已经开始的会话继续使用原版本，不因别名切换而变更执行语义。
