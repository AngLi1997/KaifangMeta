# 列表 List

> [工作台组件](README.md) · 布局容器

把容器与组件横向或纵向排成一列，按占比分配空间。按钮不直接放进列表，放进[按钮栏](button-bar.md)；需要留白时放[间隔](spacer.md)。

## 演示

### 上下结构

```xml
<List direction="vertical">
  <ButtonBar>…</ButtonBar>
  <Grid columns="2">…</Grid>
  <ButtonBar>…</ButtonBar>
</List>
```

按钮栏按内容高度显示，网格占满剩余高度。

### 纵向堆叠

```xml
<List direction="vertical">
  <Panel title="档案详情" size="67%">…</Panel>
  <Panel title="卷内文件目录">…</Panel>
</List>
```

「档案详情」占 67% 高度，另一个面板占剩余部分。

## 尺寸规则

| 子节点 | 尺寸 |
|--------|------|
| 按钮栏，以及只含按钮栏的列表 | 按内容大小 |
| 横向列表设了 `columns` | 每行 `columns` 个，等宽，超出换行；子节点的 `size` 不生效 |
| 设了 `size` 的组件与容器 | 占列表的该百分比 |
| 其他组件与容器 | 平分剩余空间（默认撑满）；横向列表里按钮栏也平分宽度 |

横向列表同时设了 `columns` 和子节点 `size` 时，设计器弹出「布局冲突」，选「按列数」清除子节点占比，选「按占比」清除列数。

## 生命周期

无自身状态，随工作台渲染。

## API

### List 属性

| 名称 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| direction | `'horizontal' \| 'vertical'` | `'vertical'` | 排列方向；组件库分别提供「横向列表」「纵向列表」 |
| columns | `number` | 不设 | 仅横向列表：每行列数，1–12 |
| gap | `number` | 横向 `8`，纵向 `12` | 间距（px） |

### 子节点属性

| 名称 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| size | `string` | 自动 | 在列表中所占百分比，常用 5%、10%、15%、25%、30%、33%、50%、67%、75%、100%，也可手动输入 1%–100%；不设时与其他未设的兄弟平分剩余空间。纵向排列里的按钮栏不适用。设计器右键「占比」或属性面板设置 |
