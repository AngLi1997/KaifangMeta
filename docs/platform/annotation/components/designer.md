# 布局设计器 LayoutDesigner

> [工作台组件](README.md) · 源码 `web/src/components/custom/workbench/LayoutDesigner.vue` · 入口：场景模板 → 模板编辑 → 标题旁按钮组「XML / 布局 / 预览」中的「布局」

拖拽摆放工作台组件，与「XML」编辑同一份模板。

## 演示

```vue
<LayoutDesigner v-model="form.config" :readonly="readonly" />
```

### 模板编辑页

标题旁的按钮组切换三种模式，编辑的是同一份模板：

| 模式 | 显示 |
|------|------|
| XML | 左侧 XML 编辑器，右侧按比例缩小的工作台预览 |
| 布局 | 拖拽设计器（新建模板默认） |
| 预览 | 工作台按实际尺寸铺满卡片，用样例数据渲染，保存、提交不生效 |

### 界面

| 部分 | 操作 |
|------|------|
| 组件库（左） | 每个组件带图标；按「布局 / 组件 / 按钮 / Label Studio / Label Studio 对象 / 控件 / 视觉」分组；拖到容器放置；悬停 1 秒预览外观，开始拖动即关闭；已放置的唯一组件置灰 |
| 画板（中） | 从空白开始，按真实嵌套显示容器；拖入的组件默认撑满所在位置（纵向列表撑满宽度、横向列表平分宽度、网格撑满单元格），按钮在按钮栏内按内容排列；落在某个组件上即插到它之前，落在容器空白处追加到末尾；画布是嵌套区，原生标签只能拖进画布 |
| 属性（右） | 列表：方向、列数（仅横向）、间距；网格：列数、行数、间距；按钮栏：水平（左 / 中 / 右 / 分散）、垂直（上 / 中 / 下）对齐、间距；面板：标题；子节点：占比（列表内，可选常用值或手动输入 1%–100%；与所在横向列表的列数冲突时弹窗选择）或跨列、跨行（网格内）；表单：名称、列数、字段；数据表格：名称、列；原生标签：`name`、数据变量、`toName`、选项 |

### 拖放规则

拖动组件库里的组件，或拖动画板里已有的组件 / 容器（整块移动）时，按光标位置决定落点：

| 光标位置 | 提示 | 松手后 |
|---------|------|--------|
| 靠近某个组件的上 / 下 / 左 / 右边（容器取 16px 边缘带，普通组件取最近的一边），且该方向与所在容器的排列方向一致 | 该边出现插入线 | 插到该组件这一侧 |
| 同上，但方向与所在容器的排列方向垂直（如纵向列表里某组件的左右两侧、横向列表里的上下两侧、网格单元格的上下两侧） | 该组件这一侧的一半区域高亮 | 把该组件与新组件包进一个同方向的列表，两者各占一半；原组件的占比、跨行跨列移到外层列表上 |
| 某个容器内部（列表、网格、面板、按钮栏、画布，包括网格单元格里的容器） | 整个容器高亮 | 放进该容器末尾，并撑满所在位置 |
| 容器内部，但该容器不收被拖的组件（如把表单拖到按钮栏里） | 按最近一边处理 | 插到该容器旁边 |
| 把按钮拖到按钮栏以外的容器（面板、列表、网格、根） | 同上 | 自动新建一个按钮栏把它包起来 |
| 不能放的位置（如把原生标签拖出画布） | 无提示 | 不响应 |

排列方向：横向列表、按钮栏、网格为左右，纵向列表、面板、工作台根为上下。按钮栏与画布内只按顺序插入，不会包列表（上 / 左视为前，下 / 右视为后）。不能把容器拖进它自己或它的子孙里。

各组件可放的位置：

| 组件 | 可放 |
|------|------|
| 网格、列表、面板、按钮栏、表单、数据表格、画布 | 工作台根或任意容器内（按钮栏除外） |
| 按钮 | 按钮栏内 |
| 间隔 | 任意容器（按钮栏内占满剩余宽度，其他容器里为 16px 空白） |
| Label Studio 标签 | 画布内 |

手写 XML 放错位置时，保存模板报错并提示应放的容器。

### 所见即所得

画板按工作台的同一套规则显示，拖进去是什么样，运行时就是什么样：

| 方面 | 画板上的表现 |
|------|------------|
| 尺寸 | 纵向列表、面板、工作台根里的组件平分剩余高度，横向列表里平分宽度，设了占比（`size`）的按百分比，横向列表设了列数的按列等分；网格里撑满单元格（各行平分高度）；纵向排列里的按钮栏按内容高度 |
| 画布 | 图像、文本、HTML、音视频等对象标签撑满画布，控件与标题文字按内容高度 |
| 按钮栏 | 按自身的水平 / 垂直对齐与间距排列按钮，间隔占满剩余宽度 |
| 间距 | 列表、网格、按钮栏使用自身设置的间距 |
| 表单 | 显示字段标签，按表单列数排布，必填带 `*`，多行文本占满一行 |
| 数据表格 | 显示列标题，设了宽度的列按宽度 |
| 图标 | 组件块与组件库使用同一图标 |

例如空白工作台里只放一个画布，画布占满整个工作台；画布里放一个图像，图像占满画布。

### 右键菜单

画板中右键任意组件或容器（根除外）：

| 菜单项 | 出现条件 | 作用 |
|--------|---------|------|
| 跨列 / 跨行 | 在网格内 | 子菜单选 1…列数 / 1…行数（未固定行数时最多 4） |
| 占比 | 在列表、面板或根内，且会伸展 | 子菜单选自动、5%、10%、15%、25%、30%、33%、50%、67%、75%、100%，或「自定义…」后在属性面板输入 |
| 上移 / 下移 | — | 在同一容器内移动一位 |
| 复制 | 不含唯一组件（按钮、画布） | 复制到下方，表单、表格、原生标签的 `name` 自动编号 |
| 选中上级 | 上级不是根 | 选中所在容器，便于编辑容器属性 |
| 删除 | — | 删除该节点及其子树 |

## 生命周期

| 阶段 | 时机 | 行为 |
|------|------|------|
| 新建 | 新建模板 | 默认 `<Workbench/>` 并打开「布局」页签，画板空白 |
| 载入 | 挂载或外部修改 XML | 解析为布局树；失败时显示错误，不覆盖 XML |
| 编辑 | 拖放、删除、改属性 | 重新生成规范格式的 XML 并写回 `v-model` |
| 旧模板 | 打开根为 `<View>` 的模板 | 按默认布局显示；不编辑就不改写，编辑后保存为 `<Workbench>` |

写回的 XML 不保留注释与自定义缩进；`<View>` 上的属性（如 `style`）在转为 `<Workbench>` 时不保留，需要时切到 XML 视图补写。

## API

### LayoutDesigner Props

| 名称 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| v-model | `string` | 必填 | 模板 XML |
| readonly | `boolean` | `false` | 只读：不能拖动、删除和改属性 |

### 布局工具函数

`web/src/components/custom/workbench/layout.ts`：

| 名称 | 类型 | 说明 |
|------|------|------|
| parseLayout | `(xml: string) => LayoutNode` | XML → 布局树（根节点），结构错误时抛出带说明的错误 |
| serializeLayout | `(root: LayoutNode) => string` | 布局树 → 规范格式 XML |
| checkLayout | `(root: LayoutNode) => string` | 规则校验（空白、唯一组件重复、名称重复、画布标签），合规时返回空串 |
| extractCanvas | `(xml: string) => string` | 取出交给编辑器的 `<View>` 原文 |
| COMPONENTS | `ComponentDef[]` | 组件库：键、标签、名称、分组、类别（容器 / 组件 / 原生标签）；新增组件先登记在这里 |
